# حزمة البشرى Technology — السودان

هذه حزمة أولية منظمة لمسودات التأسيس والإدارة والعقود والسياسات والسجلات. لم يُفترض نوع الكيان القانوني أو الولاية أو البيانات الضريبية، لذلك توجد حقول `يُعبأ`.

## مهم قبل الاستخدام
- لا تُوقّع أي مستند قانوني قبل مراجعته من محامٍ أو مستشار قانوني مرخّص في السودان.
- لا تعتبر هذه الحزمة دليلاً على استيفاء متطلبات التسجيل أو الترخيص أو الضرائب.
- يجب مطابقة كل عقد مع النشاط الفعلي، الولاية، مكان العميل، العملة، وطريقة الدفع.

## ما تحتويه الحزمة
- قوالب Word قابلة للتعديل.
- سجل Excel متعدد الأوراق.
- فهرس ونموذج بيانات الشركة وقائمة مراجعة قبل التسجيل والتشغيل.

## البيانات الناقصة التي يجب تعبئتها
الشكل القانوني، الاسم القانوني، الولاية والمحلية، المؤسسون ونسب الملكية، رأس المال، المدير/الممثل القانوني، العنوان، البريد والهاتف، الخدمات، الموقع والتطبيقات، سياسة البيانات، ومعلومات التسجيل والضرائب.


## تحديث المرحلة الثانية
تم اعتماد الشعار المرفق كالشعار الرسمي وإضافة دليل هوية بصرية وختم ونماذج مالية وتجارية وإدارية وموارد بشرية ودعم فني وحوادث وطلبات خصوصية.
