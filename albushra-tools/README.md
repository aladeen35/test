# 🇸🇩 أدوات البشري

تطبيق ويب تقدّمي (PWA) من **البشري للتكنولوجيا** يجمع أدوات يومية للمواطن السوداني. يُثبَّت على الهاتف من المتصفح، ويعمل دون إنترنت بعد أول فتح، وكل البيانات محفوظة على الجهاز فقط.

## الشاشات
- **البيت:** تحية باسمك، والتاريخ الميلادي والهجري، والساعة مع الصلاة القادمة والوقت المتبقي، وطقس مدينتك مع تنبيه الغبار والهبوب، وسعر الدولار اليوم (الموازي والرسمي)، وأدواتك المفضلة وآخر ما استخدمته.
- **الأدوات:** كل الأدوات مع بحث وتصنيفات.
- **الصلاة:** مواقيت اليوم لـ 25 مدينة في كل الولايات، أو موقعك الدقيق عبر GPS.
- **الإعدادات:** المدينة، وطريقة الحساب، وتعديل المواقيت بالدقائق، وفرق التاريخ الهجري، والمظهر، والنسخ الاحتياطي.

## الأدوات (28)
| التصنيف | الأدوات |
|---|---|
| المال والسودان 🇸🇩 | محوّل العملات (رسمي + سوق موازٍ)، تحويلات المغتربين، حاسبة الذهب، حاسبة الزكاة، الكهرباء والطاقة الشمسية، محوّل الوحدات (فدان، قيراط، جوال، جركانة…) |
| حاسبات | الآلة الحاسبة العلمية، الأقساط والمرابحة، النسب والضريبة (17% قابلة للتعديل)، تقسيم الحساب، حاسبة الصحة |
| إسلامية | اتجاه القبلة، أذكار الصباح والمساء، المسبحة، المواقيت الشهرية والإمساكية، محوّل التاريخ الهجري |
| يومية | حاسبة العمر، عدّاد المناسبات، المؤقت وساعة الإيقاف، القرعة، أرقام مهمة (اتصال وواتساب)، الطقس والغبار |
| نصوص وصور | رمز QR (إنشاء وقراءة)، مولّد كلمات المرور، ضغط الصور، أدوات النص (تشكيل، أرقام، نطق، إملاء) |
| الجهاز | الكشاف (مع SOS وشاشة بيضاء)، ميزان الماء، مقياس الضوضاء |

## ما حُذف لتكراره مع تطبيقاتك السابقة
- **من تطبيق JOO:** الملاحظات، PDF، الماسح، الكتب، البريد، الملفات، هاتفي، المصاريف، الميزانية، الاشتراكات، العادات، الأهداف، الإنجازات، المهام، التركيز، الماء، المزاج، الأرقام، نظام المستوى والنقاط.
- **من تطبيقات المستودع:** المساعد الذكي، التخطيط والخرائط، مزامنة الفريق، الألعاب.

## مصادر البيانات
- **مواقيت الصلاة:** تُحسب على الجهاز. الطريقة الافتراضية هي الهيئة المصرية العامة للمساحة (الفجر 19.5°، العشاء 17.5°)، بتوقيت `Africa/Khartoum`.
- **التاريخ الهجري:** تقويم أم القرى عبر `Intl`، مع تعديل ±يومين حسب رؤية الهلال.
- **العملات:** السعر الرسمي من `open.er-api.com` (مجاني بلا مفتاح). سعر السوق الموازي يدخله المستخدم، وتُحسب منه بقية العملات.
- **الطقس والغبار:** Open-Meteo (الطقس + جودة الهواء PM10)، بلا مفتاح.
- **QR:** مكتبة `qrcode-generator` للإنشاء، و`BarcodeDetector` أو `jsQR` للقراءة. تُحمَّل عند الحاجة فقط.

## حدود معروفة
- تنبيه الصلاة يعمل والتطبيق مفتوح أو في الخلفية القريبة؛ تطبيقات الويب لا تستطيع جدولة تنبيه والتطبيق مغلق تمامًا.
- البوصلة والفلاش وميزان الماء تعتمد على حساسات الهاتف ودعم المتصفح (الأفضل Chrome على أندرويد).
- إحداثيات المدن تقريبية؛ لدقة أعلى استخدم «موقعي الدقيق» أو التعديل اليدوي بالدقائق.

## التشغيل
```bash
cd albushra-tools
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```
وللنشر: أي استضافة ثابتة (GitHub Pages، Netlify، Cloudflare Pages).
