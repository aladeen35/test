# ✅ سلامة — مساعد ضبط جودة الغذاء

تطبيق ويب صغير بالعربية يرافق **موظف ضبط جودة الغذاء** في نوبته اليومية: يسجّل قراءات الحرارة ويحكم عليها فورًا، يدير جولة تفتيش بنقاط حرجة موزونة، يتابع صلاحية الأصناف المفتوحة والمستلمة، ويحوّل كل خروج عن الحد إلى **مخالفة بإجراء تصحيحي** لا تُغلق إلا بتوثيق. ثم يطبع من ذلك كله تقريرًا موقّعًا جاهزًا للملف.

كل شيء يعمل **على الجهاز فقط ودون اتصال** — لا حسابات ولا خادم ولا مفاتيح.

## ▶️ التشغيل

```bash
cd salamah
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

> يحتاج خادمًا (ولو محليًا) لتسجيل الـ Service Worker والعمل دون اتصال. للتجربة السريعة يكفي فتح `index.html` مباشرة.

### 📲 التثبيت كتطبيق (PWA)

افتح التطبيق من خادم أو GitHub Pages ثم **«إضافة إلى الشاشة الرئيسية»** على الهاتف (أو زر التثبيت في شريط العنوان على الحاسوب). بعد أول زيارة يعمل كليًا دون إنترنت — وهو الوضع الطبيعي داخل المطبخ والمخازن.

للتجربة بلا إدخال بيانات: **⚙️ الإعدادات → البيانات → 🧪 بيانات نموذجية**.

## 🧩 الوحدات الخمس

| التبويب | ماذا يحل |
|---|---|
| 🏠 **اليوم** | ما استحق ولم يُنجَز: نقاط لم تُقس، جولة لم تُسجّل، مخالفات حرجة أو متأخرة، أصناف قاربت الانتهاء — مع مؤشرات اليوم والتقارير |
| 🌡️ **الحرارة** | قراءة لكل نقطة قياس، حكم فوري مقابل الحد المرجعي، وإجراء تصحيحي **إلزامي** عند الخروج |
| 📋 **الجولة** | ٣٢ بندًا في ٦ أقسام بتقييم مطابق/ملاحظة/مخالف/لا ينطبق، نسبة مطابقة موزونة وتقدير |
| 🏷️ **الصلاحية** | الأصناف المفتوحة والدفعات المستلمة، الأيام المتبقية، وطباعة ملصق «يُستهلك قبل» |
| ⚠️ **المخالفات** | كل المخالفات المرصودة (تلقائية أو يدوية) مع الخطورة والمسؤول وتاريخ الإغلاق وصورة إثبات |

## 🌡️ الحدود المرجعية الافتراضية

مبنية على المتطلبات العامة لسلامة الغذاء ومبادئ الهاسب، و**كلها قابلة للتعديل** من الإعدادات لتطابق خطة الهاسب المعتمدة في منشأتك:

| نقطة القياس | المدى المسموح |
|---|---|
| ثلاجة تبريد · ثلاجة عرض/سلطات | ‎0 → 5 °C |
| مجمّد (فريزر) | ‎−30 → −18 °C |
| حفظ ساخن | ‎60 → 95 °C |
| قلب المنتج بعد الطهي | ‎75 → 100 °C |
| إعادة تسخين | ‎74 → 100 °C |
| مخزن جاف | ‎10 → 25 °C |
| ماء الغسيل الساخن | ‎60 → 90 °C |
| محلول التطهير (كلور) | ‎100 → 200 ppm |

نقاط القياس نفسها (ثلاجة الحليب، الفريزر الرئيسي، سخّان الحفظ…) تُضاف وتُحذف وتُسمّى من الإعدادات، ولكل واحدة نوع يحدد مداها.

## 🔗 المنطق الذي يربط الوحدات

هذه هي فكرة التطبيق: **لا ملاحظة بلا إجراء**.

- قراءة خارج الحد ← لا تُحفظ بدون إجراء تصحيحي مكتوب، وتُنشئ مخالفة **حرجة** تلقائيًا (أو كبيرة للمخزن الجاف والتطهير).
- بند مخالف في الجولة ← ملاحظة إلزامية، ومخالفة تلقائية باستحقاق **يوم واحد** إن كان البند حرجًا و**٧ أيام** لغيره.
- حرارة استلام غير مطابقة ← قراءة مسجَّلة + مخالفة حرجة باسم المورد.
- المخالفة **لا تُغلق** إلا بإجراء تصحيحي موثّق، ويمكن إعادة فتحها.

### حساب نسبة المطابقة

وزن البند الحرج ⚠️ = **٣ أضعاف** العادي · مطابق = ١ · ملاحظة = ٠٫٥ · مخالف = ٠ · «لا ينطبق» يُستبعد من الحساب.

| التقدير | الشرط |
|---|---|
| ممتاز | ‎≥ 95% وبلا أي بند مخالف |
| جيد | ‎≥ 85% (أو ‎≥ 95% مع بند مخالف واحد على الأقل) |
| مقبول — يحتاج تصحيح | ‎≥ 70% |
| غير مقبول | أقل من ‎70% |
| **غير مقبول — مخالفة حرجة** | أي بند حرج مخالف، أيًّا كانت النسبة |

## 📄 المخرجات

- **تقرير طباعة / PDF** لمدة اليوم أو ٧ أو ٣٠ يومًا: ملخص، سجل الحرارة كاملًا، الجولات، المخالفات وإجراءاتها، وسطر توقيع لمسؤول الجودة ومدير الفرع.
- **ملصق صنف** بمقاس ‎70mm: الاسم، الموقع، المورد/التشغيلة، تاريخ الفتح، و«يُستهلك قبل» بخط عريض.
- **تصدير CSV** (بترميز يفتح مباشرة في Excel) للحرارة والجولات والمخالفات والأصناف، و**نسخة احتياطية JSON** كاملة قابلة للاستيراد.
- **مشاركة ملخص** نصي عبر مشاركة النظام أو واتساب.

## 🗂️ بنية الملفات

```
salamah/
├── index.html              الهيكل: ٥ تبويبات + نافذة سفلية + منطقة الطباعة
├── css/style.css           نظام التصميم، الوضع الليلي، وأنماط الطباعة
├── js/data.js              الحدود المرجعية، قائمة التفتيش، التخزين، وصور IndexedDB
├── js/app.js               منطق الوحدات والتقارير والإعدادات
├── manifest.webmanifest    بيانات التطبيق للتثبيت
├── sw.js                   Service Worker للعمل دون اتصال
└── icons/                  أيقونات 192 و512
```

## 🔒 البيانات والخصوصية

- القراءات والجولات والمخالفات والإعدادات في `localStorage` تحت المفتاح `salamah:v1`، وصور المخالفات مضغوطة في IndexedDB (`salamah-photos`).
- لا يُرسل شيء لأي خادم، ولا توجد تبعيات خارجية غير خطي الويب.
- البيانات مرتبطة بالمتصفح والجهاز: صدّر نسخة احتياطية قبل تغيير الجهاز أو مسح بيانات المتصفح.

## 🛣️ أفكار للتطوير

- مؤقّت التبريد السريع (‎60→21 خلال ساعتين، ‎21→5 خلال ٤ ساعات) بتنبيه.
- سجل معايرة مقياس الحرارة بجدول تذكير.
- مزامنة اختيارية بين أجهزة الفريق (بنفس أسلوب صندوق الفريق في التطبيق الرئيسي).
- قوالب تفتيش متعددة (مطبخ · فرع تقديم · مستودع · مركبة نقل).
