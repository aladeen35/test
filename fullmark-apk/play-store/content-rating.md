# تصنيف المحتوى (IARC) — فول مارك

> المكان في Play Console: **Policy and programs → App content → Content rating → Start questionnaire**.
> الاستبيان يُعبّأ بالإنجليزية؛ الأسئلة أدناه مختصرة بصياغتها التقريبية، وقد تختلف الصياغة قليلًا في Console. أجب حسب المعنى.

---

## 1) البيانات الأساسية

| الحقل | الإجابة |
|---|---|
| Email address | `CONTACT_EMAIL` (يصل عليه شهادة التصنيف من IARC) |
| Category | **Game** (لعبة) — ليس «All Other App Types» ولا «Social». |
| نوع اللعبة (إن سُئلت) | Trivia / Quiz — مسابقة معلومات عامة. |

| القسم | السؤال (مختصر) | الإجابة | ملاحظة |
|---|---|---|---|
| **Violence** | Does the game contain violence (cartoon, fantasy or realistic), blood, gore? | **No** | لا عنف إطلاقًا. المقدّم شخصية كرتونية ودودة. |
| **Fear** | Content that may frighten young children (horror, scary scenes)? | **No** | |
| **Sexuality** | Nudity, sexual content or innuendo? | **No** | |
| **Language** | Crude language, profanity, swear words? | **No** | محتوى الأسئلة من إعداد المطوّر ونظيف. ردود الذكاء الاصطناعي مقيّدة بالتلميح، ويوجد زر للإبلاغ. |
| **Controlled substances** | References to or use of drugs, alcohol, tobacco? | **No** | ⚠️ إن وُجد سؤال معلومات عامة يذكر التدخين أو الكحول بشكل معلوماتي بحت، يبقى الجواب عادةً No لأنه ليس تصويرًا للاستخدام. راجع بنك الأسئلة إن كنت غير متأكد. |
| **Crude humor** | Bathroom humor, crude jokes? | **No** | |
| **Gambling** | Real gambling, or simulated gambling (casino, slot machines, betting)? | **No** | النقاط داخل اللعبة فقط ولا قيمة مالية لها، ولا رهانات ولا عجلات حظ. |
| **Discriminatory content** | Hate speech or discrimination? | **No** | |

## 3) أسئلة متفرقة (Miscellaneous)

| السؤال (مختصر) | الإجابة | التوضيح |
|---|---|---|
| **Does the app allow users to interact or exchange content with each other?** (Users Interact) | **Yes** | في اللعب أونلاين (رمز غرفة من 5 أرقام، أو غرفة العائلة) وفي البلوتوث، يتبادل اللاعبون **الاسم المستعار والإجابات وحالة اللعبة فقط**. **لا توجد دردشة** نصية أو صوتية، ولا تبادل صور، ولا ملفات شخصية عامة، ولا بحث عن غرباء: الدخول للغرفة فقط بمعرفة رمزها من الشخص نفسه. |
| Does the app share the user's current physical location with other users? | **No** | لا صلاحية موقع. |
| Does the app allow users to purchase digital goods? | **No** | لا مشتريات داخل التطبيق. |
| Does the app contain unrestricted internet access (e.g. a web browser or search engine)? | **No** | التطبيق لا يفتح مواقع عشوائية؛ الاتصال بالإنترنت فقط لخدمة الذكاء الاصطناعي واللعب أونلاين. |
| Is the app a web browser or search engine? | **No** | |
| Does the app contain **AI-generated content** / allow users to generate content with **generative AI**? | **Yes** | وسيلة «المساعد الذكي» في المستوى الصعب: يكتب اللاعب أو يتكلّم ويعرض التطبيق تلميحًا يولّده الذكاء الاصطناعي. الردود قصيرة ومقيّدة بموضوع السؤال، ويوجد زر «الإبلاغ عن الرد». |
| Does the app feature or promote the sale of age-restricted products (alcohol, tobacco, weapons)? | **No** | |
| Is this a news app? | **No** | |

> إن لم يظهر سؤال صريح عن الذكاء الاصطناعي في نسختك من الاستبيان، فلا مشكلة؛ الإفصاح عن الذكاء الاصطناعي التوليدي يتم أيضًا في سياسة الخصوصية وفي الالتزام بسياسة Google للذكاء الاصطناعي التوليدي (انظر `target-audience.md`).

## 4) التصنيف المتوقّع

التصنيف النهائي يُصدره IARC آليًا بعد الإرسال. المتوقّع لهذه الإجابات:

| الجهة / المنطقة | التصنيف المتوقّع |
|---|---|
| IARC العام (معظم الدول، ومنها السعودية ودول الخليج عبر Google Play) | **3+** |
| PEGI (أوروبا) | **PEGI 3** |
| ESRB (أمريكا الشمالية) | **Everyone** |
| USK (ألمانيا) | **USK 0** |
| ClassInd (البرازيل) | **L** |
| ACB (أستراليا) | **G** |

مع **عنصر تفاعلي (Interactive Element): «Users Interact»** بسبب اللعب أونلاين. هذا العنصر لا يرفع العمر، لكنه يظهر بجانب التصنيف.

> ⚠️ بعض الأنظمة قد تضيف وصفًا مثل «Unrestricted Internet» أو ملاحظة عن محتوى الذكاء الاصطناعي حسب صياغة الإجابات. إذا خرج تصنيف أعلى من المتوقع، راجع الإجابات قبل الاعتراض.

---

## 5) متى تعيد الاستبيان؟

أعد الاستبيان قبل نشر أي تحديث يضيف:
- دردشة بين اللاعبين، أو صوت/صور بين اللاعبين.
- إعلانات أو مشتريات.
- مشاركة موقع، أو متصفح داخلي.
- محتوى أسئلة يتضمن عنفًا أو موضوعات حساسة.
