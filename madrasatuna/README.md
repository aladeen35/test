# 🏫 مدرستنا — لعبة العائلة (مع أستاذ عدوي)

لعبة ذكاء وذكريات ومنافسة عائلية بروح المدرسة الكلاسيكية والهزار الخفيف، مستوحاة من برامج المسابقات المدرسية. مضيف واحد (الأستاذ/الحكم) يقرأ الأسئلة ويدير النتيجة، وفريقان يتنافسان في حصص متتالية.

## ▶️ التشغيل

تطبيق ويب ثابت لا يحتاج أي تثبيت — افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
cd madrasatuna
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

يعمل على الهاتف والحاسوب (واجهة متجاوبة RTL بالكامل).

### 📲 التثبيت كتطبيق (PWA)

اللعبة تطبيق ويب تقدّمي كامل: افتحها من خادم (أو GitHub Pages) ثم اختر **«إضافة إلى الشاشة الرئيسية»** على الهاتف أو زر التثبيت في شريط عنوان المتصفح على الحاسوب. بعد أول زيارة تعمل اللعبة **دون اتصال بالإنترنت** بفضل الـ Service Worker الذي يخزّن كل ملفات التطبيق.

## 🎮 طريقة اللعب

1. **الأستاذ (المضيف):** شخص واحد يمسك الجهاز، يقرأ الأسئلة بصوت عالٍ ويحكم بأزرار «صح ✔» و«غلط ✘».
2. **الفريقان:** لكل فريق اسم وشعار/هتاف كرتوني يُختار عند الإعداد.
3. تتوالى **الحصص** (4 أو 5)، وفي النهاية يُعلَن **بطل مدرستنا** 🏆 مع احتفال وقصاصات.

## 📚 الحصص

| الحصة | النوع | النقاط |
|---|---|---|
| 📚 حصة الأسئلة | سؤال وجواب بالتناوب (مؤقّت 30 ث) | صح = 10 |
| 📻 فاكر ولا ناسي؟ | ذكريات المدرسة وأمثال ناقصة | صح = 10 |
| 🔔 حصة الجرس | أول فريق يضرب جرسه يجاوب | صح = +10، غلط = −5 وتعدّي |
| 🤐 قول ولا تقولش | وصف الكلمة دون نطقها ولا الممنوعات (60 ث لكل فريق) | كل كلمة = 5 |
| 🏁 الحصة الأخيرة | ألغاز حاسمة بنقاط مضاعفة | صح = 20 |

## 🎨 الهوية البصرية

- **الطراز:** ريترو مدرسي دافئ (Nostalgic / Retro Vintage) — ستارة مسرح زرقاء ملكية، خشب المكتب المدرسي، سبورة خضراء بإطار خشبي، وأوراق كراسة مسطرة بهامش أحمر وثقوب.
- **الشعار:** SVG مرسوم بالكامل — كلمة «مدرستنا» بخط عريض أبيض بإطار داكن، خلفها شمس مشرقة يعلوها قوس قزح، وشريط «مع أستاذ عدوي — نسخة العائلة».
- **الخطوط:** [Marhey](https://fonts.google.com/specimen/Marhey) للعناوين (ملمس طباشيري مرح) و[Baloo Bhaijaan 2](https://fonts.google.com/specimen/Baloo+Bhaijaan+2) للنصوص.
- **الألوان:** أزرق ملكي، أخضر سبورة، أصفر شمس/برتقالي، أحمر قلم التصحيح، ذهبي للنقاط، أخضر «صح» ووردي-أحمر «غلط».
- **المؤثرات الصوتية:** مولّدة برمجيًا عبر Web Audio API بدون أي ملفات خارجية — جرس المدرسة، كتابة الطبشور، تقليب الصفحات، نغمات صح/غلط، تكتكة آخر الثواني، وموسيقى الفوز.

## 🗂️ بنية الملفات

```
madrasatuna/
├── index.html             # الشاشات السبع (بداية، شرح، إعداد، حصة، جرس، تابو، نتائج، فائز)
├── manifest.webmanifest   # تعريف الـ PWA (الاسم، الأيقونات، الألوان، RTL)
├── sw.js                  # Service Worker: تخزين التطبيق للعمل دون اتصال
├── icons/                 # أيقونات التثبيت (192 و512) مولّدة من الشعار
├── css/style.css          # الهوية البصرية الريترو المدرسية
└── js/
    ├── questions.js       # بنك الأسئلة: عام، ذكريات، جرس، تابو، ألغاز نهائية + الهتافات
    ├── audio.js           # المؤثرات الصوتية (Web Audio API)
    └── app.js             # محرك اللعبة وإدارة الحالة والشاشات
```

> صُمّمت الواجهة بالاستعانة بإضافة [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) لاختيار النمط (Vibrant & Block-based + Retro Vintage)، لوحة الألوان، والخطوط العربية.
