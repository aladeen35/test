# لوحة السيارة (CarDash)

تطبيق أندرويد يُثبَّت **على شاشة السيارة نفسها** (شاشات أندرويد الصينية مثل وحدتك: Android 15، MCU `CVD1810-WJ`).

## المزايا
| | |
|---|---|
| 🚗 **وضع القيادة** | يفتح الخرائط ويُظهر مرآة الكاميرا ونافذة يوتيوب فوقها بضغطة واحدة |
| ▶️ **يوتيوب عائم** | نافذة تُسحب وتُكبَّر وتُصغَّر، تعمل فوق الخرائط و Android Auto. زر ⌨ لتفعيل الكيبورد للبحث |
| 📷 **مرآة الكاميرا الخلفية** | الكاميرا في زاوية الشاشة طوال الوقت، معكوسة كالمرآة (⇄ عكس، ⟳ تدوير، ⇆ تبديل الكاميرا) |
| 🛑 **قفل السرعة** | عند تجاوز سرعة محددة (افتراضياً 8 كم/س) تختفي صورة الفيديو ويبقى الصوت (أو يتوقف الفيديو، حسب الإعداد) |
| 🧹 **تنظيف النظام** | يعرض التطبيقات الزائدة، ويفتح صفحتها للتعطيل، أو ينسخ أوامر ADB جاهزة |

## التثبيت (بدون كمبيوتر)
1. على الشاشة: الإعدادات ← الأمان ← السماح بالتثبيت من مصادر غير معروفة (للمتصفح أو مدير الملفات).
2. افتح المتصفح في الشاشة وحمّل:
   `https://github.com/aladeen35/test/raw/ccr-fe24ce26-x1bghb/cardash/CarDash.apk`
3. ثبّته، افتحه، واقبل الأذونات (الظهور فوق التطبيقات، الكاميرا، الموقع).

## تنظيف النظام بدون USB (ADB لاسلكي)
1. الإعدادات ← حول الجهاز ← اضغط 7 مرات على **Build number** لتفعيل خيارات المطوّر.
2. خيارات المطوّر ← **Wireless debugging** ← تشغيل ← **Pair device with pairing code**.
3. على جوالك (نفس الشبكة) ثبّت تطبيق **Bugjaeger** ← Connect ← Pair بالرمز والعنوان.
4. في التطبيق: «تنظيف النظام» ← «تحديد المقترح» ← «نسخ أوامر ADB»، والصقها في Shell داخل Bugjaeger.
   - أو من كمبيوتر: `tools/debloat.sh IP:PORT`
   - للتراجع: `pm enable <package>`

## تحديث نظام الشاشة
استخدم **About device ← Wireless Update** فقط. لا تثبّت ملفات تحديث من مصادر أخرى؛ ملف لموديل مختلف قد يعطّل الشاشة. نسختك الحالية `AJ_2025.05.23` حديثة.

## البناء
```
cd cardash && gradle assembleRelease   # يحتاج Android SDK 35
```
يُوقَّع الـ APK بمفتاح خاص غير موجود في المستودع (`app/cardash.jks` + متغير `CARDASH_KEY_PASS`)، وبدونه يُستخدم مفتاح debug.
