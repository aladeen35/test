# هاف مليون ½M — مخطط الزيارات الذكي

تطبيق ويب تقدّمي (PWA) بالعربية لتخطيط زيارات فروع سلسلة "هاف مليون"، مع مساعد ذكاء اصطناعي مدمج مدعوم بنماذج Claude.

## المزايا

### 🗓️ التخطيط
- توليد خطة أسبوعية تلقائية (الأحد–الخميس) توزّع الفروع جغرافيًا بأقصر مسار قيادة
- يوم الأحد يبدأ باجتماع الفريق (ساعتان) ثم الانطلاق من المقر
- تعديل الخطة بالسحب والإفلات أو النقل بين الأيام مع إعادة حساب التوقيتات تلقائيًا
- حلقة تقدّم أسبوعية توضح نسبة الإنجاز
- مشاركة الخطة برابط أو رمز، وتصديرها PDF أو صورة

### ✅ المهام الأسبوعية بتقييم A/B/C (جديد)
- المدير يضيف مهمة للفريق (مثل "التحقق من نكهة قهوة التقطير") فتظهر في زيارات **كل الأعضاء**، أو مهمة محلية على جهازك
- كل مهمة تُقيَّم في نموذج الزيارة: **A** مطابق تمامًا · **B** متوسط/به ملاحظة · **C** مخالف تمامًا (+ لا ينطبق) مع مربع ملاحظات — والملاحظة إلزامية عند C
- ملخص نتائج المهام في اللوحة (شريط A/B/C لكل مهمة) يعمل في نطاق الفريق المدمج، ويدخل في تقارير الذكاء وتصدير Excel
- مهام متكررة أسبوعيًا أو لأسبوع واحد، مع خيار "أنا مدير الفريق" لأدوات إدارة مهام الفريق

### 🌐 عربي / English (جديد)
- مبدّل لغة في الرأس والإعدادات — الاتجاه ينقلب RTL ⇄ LTR والمخططات تتبع اتجاه القراءة
- أسماء الفروع بالإنجليزية في الوضع الإنجليزي، والمساعد الذكي يجيب بلغة الواجهة

### 📍 إضافة فرع من الخريطة (جديد)
- زر عائم + على الخريطة: اضغط الموقع وتُفتح نافذة الإضافة بالإحداثيات معبأة تلقائيًا

### 👥 نظام الفريق (جديد)
- لوحة موحّدة تدمج نتائج زيارات **كل أعضاء الفريق** مع مبدّل "بياناتي / الفريق"
- فلترة حسب العضو، عمود العضو في السجل، وتصدير Excel يشمل الأعضاء
- قائد الفريق ينشئ صندوقًا مشتركًا (JSONBin) ويشارك المفتاح والرمز — كل عضو يرفع زياراته تلقائيًا

### 💬 الجدولة بالدردشة (جديد)
- أرسل في الدردشة قائمة بأسماء فروعك — حتى بالإنجليزية العامية: `shobra, azizyah, taif`
- النظام يطابقها مع فروعك (مطابقة ضبابية عربي/إنجليزي)، يسألك عن الأسماء الغامضة
  (طائف سيتي ووك أم طريق المطار؟) ويعرض إضافة أي فرع غير معروف كفرع جديد
- ثم يولّد جدول الأسبوع مباشرة — يعمل بالكامل على جهازك دون مفتاح API

### ✦ المساعد الذكي (جديد)
- **رؤى فورية محلية** تعمل دون إنترنت: الفروع الأعلى خطورة، قراءات جودة خارج النطاق، فروع متأخرة الزيارة، تقدم الخطة
- **مساعد محادثة** يقرأ بيانات التطبيق كاملة (الفروع، الخطة، سجل الزيارات) ويجيب بالعربية
- **تقارير أسبوعية تنفيذية** بضغطة زر، مع نسخ ومشاركة
- **اقتراح أولويات** زيارات الأسبوع القادم بناءً على سجل المخالفات
- ردود متدفقة (Streaming) مع اختيار النموذج: Opus 5 / Sonnet 5 / Haiku 4.5
- مفتاح API يُحفظ على الجهاز فقط ولا يُرفع أبدًا مع المزامنة السحابية

### ☕ الفروع
- 78 فرعًا محمّلة مسبقًا مقسّمة حسب المناطق
- إضافة فرع برابط خرائط جوجل أو العنوان الوطني أو الإحداثيات أو موقعك الحالي
- استيراد جماعي من Excel وتصدير كامل البيانات

### 🗺️ الخريطة
- خريطة تفاعلية بألوان أيام متمايزة (متحقَّق منها لعمى الألوان)
- بلاطات داكنة تلقائيًا في الوضع الليلي، مع مزوّدات احتياطية
- تسجيل الوصول "أنا وصلت" من نافذة الفرع مباشرة

### 📊 لوحة البيانات
- مؤشرات: الزيارات، المخالفات (Critical/Major/Minor)، متوسط PH وTDS، ساعات العمل
- مخطط أعمدة لتوزيع الزيارات على الأيام + شريط مخالفات مكدّس
- فلاتر بالفترة والحالة والاسم، وتصدير PDF/Excel، وزر "تقرير ذكي"

### ⚙️ عام
- أيقونات SVG في كل عناصر التفاعل وحالات hover واضحة (قائمة فحص UI/UX Pro Max)
- وضع ليلي كامل (تلقائي/يدوي) بنظام تصميم موحّد
- تنبيهات قبل موعد الانطلاق لكل زيارة
- مزامنة سحابية اختيارية بين الأجهزة عبر JSONBin
- يعمل دون اتصال (Service Worker) وقابل للتثبيت كتطبيق

## التشغيل

التطبيق ملفات ثابتة لا تحتاج خادمًا خاصًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو انشره على أي استضافة ثابتة (Netlify Drop، GitHub Pages، Cloudflare Pages).

### تفعيل الذكاء الاصطناعي
1. أنشئ مفتاح API من console.anthropic.com
2. افتح تبويب **الذكاء** ← **إعداد الذكاء** ← ألصق المفتاح واختر النموذج
3. اضغط "حفظ واختبار الاتصال"

## بنية المشروع

```
index.html            هيكل التطبيق والنوافذ
css/app.css           نظام التصميم (رموز، وضع ليلي، مكوّنات)
js/seed.js            بيانات الفروع الـ 78
js/core.js            الحالة، التخزين، المزامنة، محرك التخطيط، التصدير
js/ai.js              محرك الرؤى المحلي + عميل Claude API
js/ui.js              عرض التبويبات الستة والتشغيل
sw.js                 العمل دون اتصال
manifest.webmanifest  التثبيت كتطبيق
```
