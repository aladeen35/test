# Eng. Alaeldeen | Quality & Safety

A bilingual (Arabic RTL / English LTR) professional website with the **Quality Lamp | مصباح الجودة**
learning platform, the **Quality Toolkit**, the **Quality Dictionary** and the book **الذهب المسلوب / Stolen Gold** built into it.
The motion is cinematic and scroll-driven throughout.

## Commands

```bash
npm install
npm run dev      # local dev server with hot reload
npm run build    # production build into dist/
npm run lint     # ESLint
npm run preview  # serve the built dist/
```

`dist/` is committed, so the built site can be hosted as-is (all URLs are relative,
so it works from any sub-folder, e.g. GitHub Pages at `/test/alaeldeen/dist/`).
Run `npm run build` after every change and commit `dist/` with it.

## Stack

| Layer | What |
|---|---|
| Build | Vite 8 |
| Motion | GSAP 3: ScrollTrigger (every scroll animation is scrubbed), ScrollSmoother (smooth scroll), SplitText (masked line/word reveals), CustomEase (`cine`, `cineInOut`, `cineBack`) |
| 3D | Three.js hero: a gold particle double helix in drifting dust; the camera lerps to the pointer and the hero scroll progress; the loop pauses off-screen and in hidden tabs; lazy-loaded on the home page only |
| Styling | Tailwind CSS 4 (theme + utilities, no preflight) on top of the hand-written base in `css/` |
| Texture | Film grain on its own fixed compositor layer (`src/cinema/grain.js`), decoupled from the content DOM |
| Preloading | `src/cinema/preloader.js` waits for fonts and every `img[data-preload]`, shows real progress, then lifts like a curtain and starts the hero timeline |

Accessibility: when the visitor's system asks for reduced motion there is no preloader, smooth scroll, pinning or hidden content. The page renders static and complete, and the 3D hero shows one still frame.

## Layout

```
index.html            shell: preloader, header, #smooth-wrapper > #smooth-content > main + footer
src/main.js           entry: styles, motion engine, then the app scripts
src/cinema/index.js   scenes per route (hero, marquee, chapters, numbers, book, quote, page headers, reveals)
src/cinema/hero3d.js  Three.js scene
src/styles/           tailwind.css, cinema.css
js/                   app (router, pages), tools, content, i18n
css/                  base styles
public/               images, CV PDFs, manifest, service worker (copied as-is)
```

|---|---|

| Knowledge Center, Projects, Books, All links, Contact, Privacy | `#/knowledge`, `#/projects`, `#/books`, `#/links`, `#/contact`, `#/privacy` |

## Editing content

- `js/content.js`: profile (`careerStart: 2020` drives the "years of experience" figures), experience, certificates, lessons, quizzes, dictionary, articles, projects, books, links. Each text is `{ ar: "...", en: "..." }`.
- `js/i18n.js`: interface labels.
- After changing files: `npm run build`, and bump `VERSION` in `public/sw.js` so installed copies refresh.

## Before going live

- CV PDFs in `public/cv/` are generated by `node tools/make-cv.cjs public/cv` (edit the data at the top of that script, then rebuild the site).
- Linktree lists two Instagram accounts (`ala_deen_35` as a button, `aladeen35` as an icon); the site uses `ala_deen_35`.
- "Stolen Gold" links to its YouTube presentation (the only link on Linktree). Set `url` on the book if there's a PDF or store link.
