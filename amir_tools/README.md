# 🇸🇩 أدوات أمير

تطبيق **Flutter** (أندرويد وآيفون والويب) من **البشري للتكنولوجيا**: أكثر من 40 أداة يومية للمواطن السوداني، بواجهة عربية وكلمات سودانية، وتصميم تراثي بُني وذهبي مستوحى من «ألعاب أبو جنان».

## الشاشات
| الشاشة | المحتوى |
|---|---|
| **البيت** | الشعار، التحية باسمك، التاريخ الميلادي والهجري، شريط المستوى والنقاط، الساعة والصلاة الجاية فوق رسمة النيل وأهرامات مروي، الطقس مع تنبيه الهبوب، سعر الدولار الموازي والرسمي، **مفضلاتك** (4–5 أدوات في الصف، قابلة للترتيب)، مَثَل سوداني لكل يوم، وآخر الأدوات |
| **العِدّة** | كل الأدوات في أقسام مع بحث وتصنيفات — ضغطة طويلة تضيف للمفضلة |
| **الصلاة** | مواقيت 32 مدينة في كل الولايات (أو موقعك بالـ GPS)، عدّاد تنازلي، تسجيل الصلوات بالنقاط، الثلث الأخير من الليل، وأدوات الصلاة |
| **نقاطي** | المستوى واللقب، 16 إنجاز، الإحصائيات، وسجل النقاط |
| **الضبط** | الاسم، المدينة، الشكل (تراثي بني / رملي فاتح)، **تفعيل نظام النقاط**، طريقة حساب الصلاة وتعديلها بالدقائق، تنبيهات الأذان، رمز القفل، والنسخ الاحتياطي |

## الأدوات
- **المال والسوق:** الدولار والعملات (موازي ورسمي مع سجل الأسعار)، تحويلات المغتربين، الذهب، الزكاة (مال وزروع وأنعام)، الكهرباء والطاقة الشمسية، محوّل الوحدات (فدان، قيراط، جوال، جركانة…)، الأقساط والمرابحة، النسب والضريبة، قسمة الحساب، تفقيط المبالغ
- **دين ودنيا:** القبلة (بوصلة مع تعويض الميلان)، الأذكار، المسبحة، المواقيت الشهرية والإمساكية، محوّل التواريخ (هجري/قبطي/إثيوبي)، المناسبات، أسماء الله الحسنى
- **يومياتك:** حاسبة العمر المفصّلة (بالثواني، الكواكب، الهجري، القبطي، الإثيوبي، الأبراج مع تنبيه أنها كذب وشرك)، الآلة الحاسبة العلمية، المؤقت، التركيز، القرعة، أرقام مهمة، الطقس والغبار
- **صحتك:** الموية، النوم والمزاج، حاسبة الصحة، حاسبة الحمل
- **نصوص وصور:** QR، كلمات السر، الخزنة السرية المشفّرة، ضغط الصور، أدوات النص (نطق وإملاء)
- **جهازك:** الكشاف (SOS ووميض)، هاتفي، البوصلة والموقع، ميزان الموية، المسطرة، مقياس الضوضاء

## التشغيل والبناء
```bash
cd amir_tools
flutter pub get
flutter run                 # على جهاز أو محاكي
flutter build apk --release # ملف APK للأندرويد
flutter build web           # نسخة ويب
```
كل دفعة (push) على مجلد `amir_tools` تبني ملف APK تلقائيًا عبر GitHub Actions (`.github/workflows/amir-tools-apk.yml`)، وتلقاه في صفحة التشغيل تحت **Artifacts** باسم `amir-tools-apk`.

## مصادر البيانات
- المواقيت والقبلة والتقاويم: حساب محلي كامل (الهيئة المصرية العامة للمساحة افتراضيًا، توقيت السودان UTC+2). الهجري بتقويم أم القرى مع تعديل الرؤية.
- العملات: `open.er-api.com` للسعر الرسمي، والسعر الموازي يدخله المستخدم.
- الطقس والغبار: Open-Meteo (بلا مفاتيح).
- كل البيانات محفوظة على الجهاز فقط.

## البنية
```
lib/
├── main.dart              التشغيل والبوابة (ترحيب ← قفل ← التطبيق)
├── core/                  الألوان، الزخارف، الحالة والنقاط، الويدجتس المشتركة، البيانات
├── services/              الصلاة، التقاويم، الشبكة، التنبيهات
├── screens/               البيت، العِدّة، الصلاة، نقاطي، الضبط، الترحيب، القفل
└── tools/<قسم>/           كل أداة في ملف، وسجلّ لكل قسم
```
